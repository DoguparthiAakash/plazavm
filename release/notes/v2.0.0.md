# PlazaVM v2.0.0 Release Notes

PlazaVM v2 is a ground-up rebuild of the universal workspace platform.

---

## 🌟 Highlights

- **Workspace-First Architecture**: Abstract execution runtimes behind a unified workspace model.
- **5 Execution Plugins**: Docker, VirtualBox, QEMU, Podman, and Hyper-V execution plugins.
- **Composition Root DI**: Thread-safe bootstrap in `plaza-api::bootstrap`.
- **Evidence-Driven QA Certification**: 16-stage automated validation pipeline in `plaza-cli validate`.
- **Desktop Shell**: Tauri v2 + React 19 graphical user interface.
